# CodeAlpha - Student Performance Analysis

This project analyzes student academic performance to understand what factors affect results, such as study habits, school resources, family background, and financial support.

Tools Used
•	Microsoft Excel / Power BI for analysis and charts

Key Focus
•	How study habits affect performance
•	How school resources affect performance
•	How background and support affect performance
